# Demo

工程反例游乐场。

把一致性、故障恢复、架构取舍和评价标准做成可以亲手操作的小游戏。每款游戏拥有自己的事实剧本、运行状态和实验规则，共用一个简洁入口。

## 第一款游戏

- [《面试官眼前一亮》](games/interviewer-eye-opener/README.md)

  同一个点赞需求，五种流派，五种评价标准。玩家会先逐张判断七组工程方案，再带着入场记录进入连续演进的事故世界；最后由现场行为回答“你说的”和“你做的”是不是一回事。

游戏里发生的是明确标注的确定性仿真，适合反复试方案、看代价。仓库里另外保留了一条真实实验：S0—S6 会在真实 MySQL 上重放，并由独立裁判留下资格报告。仿真不会冒充真实基础设施测试，真实实验也不会替游戏决定什么算好玩。
